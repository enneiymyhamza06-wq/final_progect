# Delicious — Restaurant Website

Un site web moderne et responsive inspiré du template Delicious de BootstrapMade.
Le projet est développé avec HTML, CSS/SASS/SCSS et Bootstrap 5.

---

## Description

Ce site présente un restaurant avec un design professionnel et soigné.  
Il contient les sections principales suivantes :

- Hero : image principale avec texte et bouton d’appel à l’action.
- About : présentation du restaurant.
- Why Us : arguments et points forts du restaurant.
- Menu : catégories de plats et liste des repas proposés.
- Specials : plats spéciaux mis en avant.
- Events : évènements et offres spéciales.
- Chefs : présentation de l’équipe de chefs avec effets au survol et liens sociaux.
- Gallery : galerie d’images responsive.
- Contact : coordonnées, carte intégrée et formulaire de contact.
- Footer : liens rapides et liens vers les réseaux sociaux.

L’ensemble du site est entièrement responsive.
